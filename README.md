# Singlish Transliteration Accuracy Testing

Playwright-based automation for testing the Chat Sinhala transliteration function at [pixelssuite.com/chat-translator](https://www.pixelssuite.com/chat-translator).

This project contains **50 negative test cases** (inputs where the system fails to correctly convert chat-style Singlish into Sinhala), covering all 24 Singlish input types defined in the assignment.

---

## Prerequisites

- **Python 3.11 or 3.12** — [Download](https://www.python.org/downloads/)
- **pip** (bundled with Python)
- **Google Chrome** (recommended) or Chromium (installed automatically by Playwright)

---

## Installation (one-time)

Open a terminal / Command Prompt in this project folder and run:

```bash
# 1. Upgrade pip
pip install -U pip

# 2. Install Python dependencies
pip install -r requirements.txt

# 3. Install Playwright browsers
playwright install chromium
```

## Step 1 — Generate the Excel File

Run this **once** to create the Excel file with all 50 test cases pre-filled (TC ID, Input length type, Input, Expected output):

```bash
python create_excel.py
```

This creates `Assignment 1 - Test cases.xlsx` in the project root.

> Do **not** manually fill in the *Actual output* or *Status* columns — the automation script fills these automatically.

---

## Step 2 — Run the Automation

```bash
python test_automation.py ^
  --excel "Assignment 1 - Test cases.xlsx" ^
  --url "https://www.pixelssuite.com/chat-translator" ^
  --wait-ms 5000 ^
  --type-delay-ms 80 ^
  --slow-mo-ms 200 ^
  --save-every 1 ^
  --keep-open
```

### Arguments

| Argument | Default | Description |
|---|---|---|
| `--excel` | *(required)* | Path to the Excel file |
| `--url` | *(required)* | URL of the chat translator |
| `--wait-ms` | `5000` | Milliseconds to wait after clicking Transliterate |
| `--type-delay-ms` | `80` | Delay between keystrokes in ms |
| `--slow-mo-ms` | `200` | Playwright slow-motion delay in ms |
| `--save-every` | `1` | Save Excel after every N test cases |
| `--keep-open` | flag | Keep the browser open after tests finish |

---

## Step 3 — Review Results

Open `Assignment 1 - Test cases.xlsx`. The script automatically fills:
- **Actual output** — what the system returned
- **Status** — `Pass` (green) or `Fail` (red)

Then manually complete the two final columns:
- **Singlish input types covered**
- **Evidence or rationale for the input type covered**

These are already pre-filled in the Excel file generated by `create_excel.py`.
